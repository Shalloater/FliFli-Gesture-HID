# 更新记录

以下记录按版本倒序排列，各条内容描述对应版本发布时的变化。当前功能以[使用指南](../README.md)为准。

## 1.5.17 更新

- 已有动作支持同时编辑触发手势与发送信号，可修改手指数、连击次数、点按区域、滑动方向或动作类型
- 编辑使用独立草稿，完成后一起保存；取消或返回不修改原绑定，更换手势保留原信号
- 冲突检查排除正在编辑的条目自身，阻止与其他动作重复或区域重叠；保留缩略图及长按演示
- 主线版本号为 `1.5.17`（`versionCode = 23`），安装包为 `FliFli-v1.5.17.apk`

## 1.5.16 更新

- 将已确认的 77 个 SVG 演示接入 App：18 个触控信号、45 个点按区域组合、14 个滑动及画圈动作
- 动作列表、区域选择、已添加动作和触控信号显示对应缩略图，长按打开演示；已配置而不可重复选择的动作仍可查看演示
- 演示使用安装包内资源离线播放，支持暂停、重播、速度和进度，跟随五种语言与皮肤
- 保留点击选择与原有绑定规则；查看或关闭演示不发送输入，弹窗关闭后释放播放资源
- 主线版本号为 `1.5.16`（`versionCode = 22`），安装包为 `FliFli-v1.5.16.apk`

## 1.5.15 更新

- Android 控制与媒体控制的音量按钮简写为「音量+」「音量-」，候选摘要保留发送类别以便区分
- 电源键名称去除实验字样，键盘提示去除 QWERTY 排列前缀，删除 Android 控制顶部的说明段落
- 制作独立 SVG 演示预览，位于 `output/gesture-previews/`；动画及长按入口尚未接入 App，安装包只包含本次文案调整
- 主线版本号为 `1.5.15`（`versionCode = 21`），安装包为 `FliFli-v1.5.15.apk`

## 1.5.14 更新

- 新增顶部右侧垂直下拉
- 新增左侧边缘上滑/下滑、右侧边缘上滑/下滑；四个侧边信号统一使用固定长度
- 新信号继续沿用单指触控报告、连续轨迹和抬起结束帧
- 主线版本号为 `1.5.14`（`versionCode = 20`），安装包为 `FliFli-v1.5.14.apk`

## 1.5.13 更新

- 修复多指点按把第一根落指与最后一根抬指之间的距离误算为移动的问题，点按与滑动均按稳定的逐指轨迹判断
- 修复第二次触摸尚未结束就结算上一次点按、快速单击被合并成未配置双击而丢失的问题
- 单指、双指、三指的单击/双击/三击共用优化后的连击逻辑，保留双指捏合退出和现有动作绑定
- 排除拖出后返回及长按造成的误点按；取消、失焦、移除界面时清理待发送点按
- 主线版本号为 `1.5.13`（`versionCode = 19`），安装包为 `FliFli-v1.5.13.apk`

## 1.5.12 更新

- 「触控手势」作为正式信号分类，去除实验字样和实验说明，保留原有动作与配置
- 新增七种边缘触控信号，对应阅读器的顶部、左右侧、底部三个区域及右上角斜滑
- 新信号支持单选及序列发送，沿用主题、单指报告与释放流程；HID 描述符保持不变
- 主线版本号为 `1.5.12`（`versionCode = 18`），安装包为 `FliFli-v1.5.12.apk`

## 1.5.11 更新

- 信号选择器区分下划线标签、候选文字框、操作按钮和键帽；收紧撤销、清空按钮，保持按键大小并统一横纵间距
- 键盘与上方选择区使用独立容器，复用五种皮肤颜色
- 合并「新增点按」「新增滑动」为「新增动作」，在同一弹窗中通过点按、滑动标签切换
- 主线版本号为 `1.5.11`（`versionCode = 17`），安装包为 `FliFli-v1.5.11.apk`

## 1.5.10 更新

- 框外起滑时延迟到轨迹入框才发送触摸，按下位置为轨迹与边界的首次交点，支持上下边缘及斜向滑入、批量历史采样
- 移除多触点透传及相关界面说明，只保留单指输入；增加手指时释放远端触摸，全部抬手后恢复
- 所有全屏键盘统一使用双指向内捏合退出；电脑键盘退出时释放已按下的键，手势键盘的双指点按仍可使用
- 屏幕固定说明补充系统确认、解除固定后锁屏的原因及系统设置；应用不重复确认、不主动锁屏
- 安全区仍为系统安全范围内最大的 3:4 区域，主题边界及背景保持原样
- 主线版本号为 `1.5.10`（`versionCode = 16`），安装包为 `FliFli-v1.5.10.apk`

## 1.5.9 更新

- 新增默认开启的最大 3:4 安全触控区，可关闭；竖屏可用高度足够时左右满宽，区域边界映射目标整屏
- 修正触点计数、抬起后的记录排列和空触点结束帧
- 去除应用重复的固定确认/成功提示，只保留系统确认及必要错误提示
- 普通应用无法取消系统解除固定或锁屏手势，请从安全区边界而非手机物理边缘起滑
- 主线版本号为 `1.5.9`（`versionCode = 15`），安装包为 `FliFli-v1.5.9.apk`

## 1.5.8 更新

- 修复同一键盘切换振动反馈、强度等设置时页面跳回顶部的问题，在首次绘制前恢复滚动位置
- 界面用词统一为「振动反馈」「振动强度」
- 加强透传退出重进的会话隔离与触点释放，增加连续重进回归测试；特定设备仍需实机复测
- 透传默认采用沉浸全屏、边缘返回防护和 2 秒内两次返回确认；提供可选屏幕固定保护，增强 Home 防误触，退出时解除本应用发起的固定
- 主线版本号为 `1.5.8`（`versionCode = 14`），安装包为 `FliFli-v1.5.8.apk`

## 1.5.7 更新

- 在键盘种类中新增「触控透传」，支持按比例实时跟随
- 提供横屏/竖屏、纯黑/自定义背景和振动设置；支持捏合退出
- 将原「全屏手势键盘」的界面名称统一为「手势键盘」，保留已有配置标识
- 将触摸屏报告扩展为两个并行触点；原有触控动作配置保持兼容，但需要重新配对
- 主线版本号为 `1.5.7`（`versionCode = 13`），安装包为 `FliFli-v1.5.7.apk`

## 1.5.6 更新

- 将信号选择中的 `Meta` / `R Meta` 改为 `Win` / `R Win`，保留原有按键映射和配置 ID
- 修复触摸屏单槽位导致 Android 坐标解析异常的问题，保留原有触控手势与配置 ID
- 增加 HID 协商日志（标签 `FliFliHID`），记录主机报告查询、协议模式及发送拒绝，辅助定位特定机型的兼容问题
- 主线版本号为 `1.5.6`（`versionCode = 12`），安装包为 `FliFli-v1.5.6.apk`

## 1.5.5 更新

- 信号选择支持单个、组合、序列三种模式，组合键可自行搭配，序列支持逐步编辑与调整间隔
- 新增键盘按键、Android 控制、媒体控制及触控分类，沿用五种皮肤和五种语言
- 主线触控支持四向滑动、屏幕中心单击和双击
- 主线版本号升为 `1.5.5`（`versionCode = 11`），安装包为 `FliFli-v1.5.5.apk`

## 1.5.4 更新

- 首页、连接、设置采用统一标题和底部导航；首页直接展示设备连接状态与键盘列表
- 手势键盘、电脑键盘、首页、连接、设置和刷新按钮使用统一的矢量图标；连接图标随连接状态切换
- 新增五种清透柔和的皮肤，桌面图标沿用原版波浪图案并随皮肤变色
- 新增英文、简体中文、繁体中文、韩语、日语切换，并保存语言与皮肤偏好
