# FliFli v1.5.19

本次发布包含 1.5.18 和 1.5.19 的更新，新增屏幕比例选择、键盘配置码分享，并优化设置页按钮。

## 屏幕比例与示意图

- 触控透传提供 12 种常用比例，覆盖阅读器、手机、平板和显示器，每项都有形状示意。
- 支持自定义宽高、输入小数和交换宽高。
- 安全触控区按所选比例取最大可用尺寸；已有键盘默认保持 3:4。
- 请按受控屏幕当前方向设置「宽 : 高」。关闭安全触控区时，仍使用手机全屏。

## 键盘配置码

- 在键盘编辑页点击「配置码 → 导出配置码」，即可复制、分享或保存。
- 在设置页点击「导入」，粘贴完整配置码，查看预览后导入为新键盘，已有键盘不会被覆盖。
- 保留键盘名称、手势与信号、使用方向、振动及触控透传设置。
- 配置码不包含蓝牙配对、全局皮肤语言或自选背景图片；图片需在新设备上重新选择。

## 界面优化

- 「导入」「新增」按钮更紧凑，间距更清楚，以浅描边和主题填色区分主次。
- 保留足够的点击范围，并适配大字体；自定义比例输入窗口也会随屏幕键盘调整高度。

## 下载与升级

下载附件 **FliFli-v1.5.19.apk**，安装到 Android 9.0 或以上且支持蓝牙键盘设备功能的手机。

可覆盖安装并保留已有配置。从 1.5.17 升级时，蓝牙配对可继续使用。触控效果取决于受控设备的系统与应用。

完整操作方法见[使用指南](../../README.md)，历史变化见[更新记录](../CHANGELOG.md)。安装包校验值见附件 `SHA256SUMS.txt`。
