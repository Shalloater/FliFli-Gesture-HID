# FliFli Gesture HID 宣传图

这组宣传图采用 1080×1440 竖版 SVG，中文产品名为“翻翻 · 蓝牙手势键盘”，公开项目名为“FliFli Gesture HID”。

- `01-cover.svg`：品牌主视觉
- `02-connect.svg`：使用场景泡泡墙，以墨水屏阅读器翻页为主
- `03-gesture.svg`：手势输入能力
- `04-configure.svg`：自定义键盘与动作配置
- `05-background.svg`：纯黑与自选图像触摸背景

五页使用与 App 图标一致的白色留白、浅蓝到深蓝渐变和层叠水波元素。画圈符号参考用户提供的循环箭头，以标准圆弧重绘。PNG 可用于 GitHub Release、README 配图或社交平台长图。

`preview/` 内提供同名的 1080×1440 PNG 成图，`overview-v2.jpg` 为五页总览，`FliFli-promo-5pages-v2.zip` 为新版打包。图中的设备与配置卡片是功能示意，并非 App 实际截图。

使用场景需设备支持蓝牙 HID，且目标应用支持相应按键或已设置按键映射。墨水屏阅读器的兼容性取决于具体设备及阅读软件。
