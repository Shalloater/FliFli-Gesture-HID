# FliFli 手势演示预览

这是已获确认的 SVG 动画方案，现已接入 App 1.5.16 的长按演示与缩略图。本目录保留独立预览。

打开 `index.html` 即可离线查看；也可通过本地预览地址查看。浏览器建议使用 Edge、Chrome、Firefox 或 Safari 的较新版本。

## 范围

- **18 个触控信号**：当前信号库全部触控动作。坐标、方向和接触次数来自生产代码导出的 `touch-signals.json`。
- **45 个点按组合**：单／双／三指 × 单击／双击／三击 × 全屏／左半屏／右半屏／上半屏／下半屏。
- **14 个移动动作**：单／双／三指的四向滑动，以及单指顺时针、逆时针画圈。
- 合计 **77 个独立动画 SVG**，位于 `svg/`，文件与动作的对应关系在 `manifest.json`。

## 看法

- 浅色屏幕：受控端收到的触控轨迹。
- 深色屏幕：用户在本机怎样触发动作；高亮区域是有效范围。
- 数字 1／2／3：同一组手指。实心触点表示按下，淡出表示抬起。
- 触控信号按实际发送时间的 4 倍慢放，便于看清起点、方向与抬起。屏幕采用 3:4 示意比例，画面不模拟具体品牌的系统界面。
- 动作动画说明操作方式；实际识别容差和连击时间仍由 App 判断。点按应轻点并抬起，不是长按。

## 预览操作

点选条目播放；长按条目约半秒或点击“放大预览”，可模拟以后长按看演示的体验。支持暂停、重播、速度切换、进度拖动、五种配色和手机尺寸布局。切换点按区域会保留当前的手指数与点击次数。

SVG 使用原生矢量图形及 SMIL 动画，无外部图片、字体或网络依赖。每个文件可以单独打开、编辑；页面中的配色由 `--accent`、`--soft` 两个变量控制。当前文件默认使用紫色皮肤。

App 通过 `tools/sync_gesture_demos.py` 将已确认的 SVG 和轨迹数据同步到 `app/src/main/assets/gesture_demos/`。列表缩略图用相同坐标原生绘制，长按时才创建本地 SVG 播放窗口。独立预览站点不随 App 打包。
